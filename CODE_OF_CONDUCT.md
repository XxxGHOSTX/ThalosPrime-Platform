# Code of Conduct

## Our Pledge

In the interest of fostering an open and professional environment, contributors and maintainers pledge to make participation in the Thalos Prime project a respectful and productive experience for everyone.

## Our Standards

**Expected behavior:**
- Using professional and respectful language
- Accepting constructive feedback gracefully
- Focusing on what is best for the platform and its governance mission
- Maintaining confidentiality of proprietary logic and IP

**Unacceptable behavior:**
- Unauthorized use, copying, or redistribution of proprietary code
- Harassment or derogatory comments toward contributors
- Publishing private information without explicit permission
- Introducing security vulnerabilities knowingly

## Ownership & IP

All code in this repository is the exclusive property of **Tony Ray Macier III**.
See `docs/GOVERNANCE.md` and `docs/SECURITY.md` for the full ownership and contribution policy.

## Enforcement

Violations may be reported directly to the repository owner. All reports will be reviewed and addressed promptly. Maintainers have the right to remove content or revoke access for violations of this Code of Conduct.

## Scope

This Code of Conduct applies to all project spaces — issues, pull requests, commits, and any communication channels related to the Thalos Prime platform.
